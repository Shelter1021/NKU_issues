# 零知识证明实验：方程知识证明 (libsnark 实践)

## 1. 实验目标
本实验旨在实现一个基于 **zk-SNARKs** (零知识简洁非交互式知识论证) 的系统。证明者（Alice）需要向验证者（Bob）证明她知道方程 $x^3 + x + 5 = out$ 的解 $x$，而无需透露 $x$ 的具体数值。
* **公开输入 (Public Input)**: $out = 35$
* **私密见证 (Private Witness)**: $x = 3$

## 2. 代码结构与作用
本项目由五个核心文件组成，完整覆盖了 zk-SNARKs 的三个主要阶段：**Setup（设置）**、**Prove（证明）** 和 **Verify（验证）**。

* **`common.hpp`**
    * **核心逻辑**：定义 R1CS（Rank-1 Constraint System）约束系统。
    * **约束拆解**：将高次方程 $x^3 + x + 5 = out$ 转化为三个线性约束：
        1. $x \cdot x = x\_sq$
        2. $x\_sq \cdot x = x\_cu$
        3. $1 \cdot (x\_cu + x + 5) = out$
    * **作用**：确保证明者必须持有满足逻辑关系的变量才能通过系统的检查。

* **`mysetup.cpp`**
    * **作用**：初始化公共参数并生成密钥对。
    * **产物**：生成证明密钥 `pk.raw`（交给证明者）和验证密钥 `vk.raw`（交给验证者）。

* **`myprove.cpp`**
    * **作用**：证明者（Alice）使用。
    * **流程**：读取 `pk.raw`，输入私密解 $x$，计算辅助变量（Witness）并生成零知识证明文件 `proof.raw`。
    * **安全性**：如果输入的 $x$ 不满足方程，约束系统检查（is_satisfied）将失败，无法生成有效证明。

* **`myverify.cpp`**
    * **作用**：验证者（Bob）使用。
    * **流程**：仅读取 `vk.raw`、`proof.raw` 和公开输入 `out`。
    * **结果**：输出验证结果（1 为成功，0 为失败）。此过程无需接触私密解 $x$。

* **`CMakeLists.txt`**
    * **作用**：编译配置文件。负责链接 `libsnark`、`libff`、`gmp` 等密码学基础库，并配置 `CURVE_ALT_BN128` 椭圆曲线参数。

## 3. 实验运行步骤
1.  **编译**：`cmake . && make`
2.  **生成密钥**：运行 `./mysetup`，生成环境文件。
3.  **生成证明**：运行 `./myprove 3`，证明者生成其持有的“知识”证明。
4.  **验证证明**：运行 `./myverify`，输入公开值 `35`。若返回 **1**，则实验任务圆满完成。

## 4. 实验总结
本代码紧扣“方程知识证明”任务，通过将代数方程 R1CS 化，利用 `libsnark` 库实现了非交互式的零知识证明过程。实验成功展示了在不泄露隐私数据（$x$）的前提下，实现数据计算正确性验证的安全机制。
